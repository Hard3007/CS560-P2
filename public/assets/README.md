# Logo

`arrow-up-right.svg` is from [Feather](https://github.com/feathericons/feather), used for the homepage links. Its MIT license is included in `feather-LICENSE.txt`.

`recallguard-mark.png` is the transparent logo image used in the header. It combines a shield outline with a circular lens. The RecallGuard name beside it is rendered as text using Alliance No.1.

`northeastern-seal.png` is the black university seal used in the footer, from the [Northeastern Brand Center](https://brand.northeastern.edu/logos/seal/). The university mark is not covered by this project's MIT license.
